# פרויקט גיט קבוצתי: אתר משפטי השראה 🌟

ברוכות הבאות לתרגיל המעשי שלנו בבקרת תצורה (Git)! 
המטרה של התרגיל הזה היא ללמוד איך עובדים יחד על מאגר (Repository) משותף בלי לדרוך אחת לשנייה על הקבצים.

## מה צריך לעשות?

1. **למצוא משפט לחיים:** בחרי משפט אחד קצר שמעניק לך השראה.
2. **ליצור קובץ חדש:** 
   * צצרי קובץ HTML חדש בתיקיית הפרויקט שלך.
   * תני לו שם באנגלית שמזוהה איתך (לדוגמה: `miri.html`, `sarah.html`).
3. **לכתוב את הקוד:** 
   * אפשר להיעזר בדוגמה של `chavi.html` כדי לראות איך לעצב את העמוד בצורה נקייה ונעימה.
   * ודאי שיש בעמוד שלך קישור חזרה לדף הבית (`index.html`).
4. **עדכון דף הבית:**
   * הוסיפי את השם שלך ואת הקישור לקובץ שיצרת בתוך רשימת הקישורים בקובץ `index.html`.
5. **שליחת השינויים (Git Workflow):**
   * `git add .`
   * `git commit -m "Add [השם שלך] personal page"`
   * `git push`

בהצלחה רבה בהמשך הלמידה!
